# OIBSIP – Python Programming Internship

## 📌 About the Repository

This repository contains the Python projects developed as part of the **Oasis Infobyte Python Programming Internship**.

The projects demonstrate practical applications of Python through **voice-based interaction, automation, API integration, GUI development, input validation, secure password generation, and problem-solving**.

---

## 🚀 Projects

### 🎙️ Task 1 – Voice Assistant

A Python-based voice assistant that understands voice commands and performs various tasks such as **web searches, weather updates, reminders, email sending, website navigation, and general knowledge queries using Google Gemini AI**.

**Key Features:**

* Voice command recognition
* Greeting and conversational responses
* Date and time information
* Web search
* Weather information
* Reminder creation
* Email sending
* Website navigation
* Custom search commands
* General knowledge assistance using Gemini AI
* Handling of invalid or unrecognized commands
* Text-to-speech responses

**Technologies:**

`Python` `NLTK` `SpeechRecognition` `pyttsx3` `OpenWeather API` `Google Gemini API` `Gmail SMTP`

**Project:** [View Voice Assistant](https://github.com/Sidharthrahul04/OIBSIP/tree/main/Python-Task1-VoiceAssistant)

---

### 🧮 Task 2 – BMI Calculator

A lightweight **command-line BMI Calculator** developed using Python. The application accepts the user's weight and height, calculates their **Body Mass Index (BMI)**, and classifies the result according to standard BMI categories.

**Key Features:**

* Weight input in kilograms
* Height input in meters
* BMI calculation
* BMI category classification
* Input validation
* Handling of invalid inputs
* Exception handling

**Technologies:**

`Python` `Conditional Statements` `Input Validation` `Exception Handling`

**Project:** [View BMI Calculator](https://github.com/Sidharthrahul04/OIBSIP/tree/main/Python-Task2-BMICalculator)

---

### 🔐 Task 3 – Random Password Generator

A graphical password generator developed using **Python and Tkinter**, designed to generate customizable and secure passwords.

**Key Features:**

* Customizable password length
* Selection of character types
* Secure password generation using Python's `secrets` module
* Password strength evaluation
* Option to exclude ambiguous characters
* One-click password copying
* Session-based history of the last five generated passwords

**Technologies:**

`Python` `Tkinter` `secrets` `pyperclip`

**Project:** [View Random Password Generator](https://github.com/Sidharthrahul04/OIBSIP/tree/main/Python-Task3-RandomPasswordGenerator)
